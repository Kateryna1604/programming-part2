## Хід роботи

У роботі було реалізовано однозв’язний список для зберігання повідомлень.

**Для цього створено структуру вузла Node, яка містить:**

дані повідомлення;
покажчик на наступний елемент списку.

Також було реалізовано структуру MailList, яка містить:

покажчик на перший елемент списку;
кількість елементів.

**У програмі реалізовано:**

додавання елементів у список;
видалення елементів;
пошук повідомлень;
сортування списку;
підрахунок розміру повідомлень;
повне очищення списку.

Додатково була створена консольна система меню для взаємодії користувача з програмою.

## Результати виконання

Програма дозволяє працювати зі списком повідомлень через текстове меню та виконувати всі необхідні операції над даними.

**Було перевірено:**

додавання нових повідомлень;
видалення повідомлень;
пошук за відправником;
сортування за темою;
коректне звільнення пам’яті.
