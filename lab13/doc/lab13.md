# Laboratory work 13

## Topic
Working with files in C language.

## Purpose
Learn how to work with files using fopen(), fscanf(), fprintf(), fclose().

## Project structure

lab13/
- src/
- assets/
- doc/
- test/

## Program description

The program:
1. Opens input file.
2. Reads integers.
3. Calculates:
   - minimum value,
   - maximum value,
   - average value,
   - count of even numbers.
4. Saves result into output file.

## Input data

Input file:
assets/input.txt

Example:

5 10 7 2 8 15 20

## Output data

Output file:
assets/output.txt

Example:

Minimum: 2
Maximum: 20
Average: 9.57
Even numbers: 4

## Conclusion

During laboratory work file operations in C language were learned:
- fopen()
- fclose()
- fscanf()
- fprintf()
