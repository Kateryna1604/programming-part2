## Хід роботи

У лабораторній роботі було реалізовано програму для обробки матриці, що зберігається у текстовому файлі.

Було створено такі функції:

read_matrix() — зчитування матриці з файлу;
find_max() — пошук максимального елемента матриці;
write_result() — запис результату у вихідний файл.

Матриця зчитується з файлу assets/input.txt. Перший рядок містить кількість рядків та стовпців матриці, а наступні рядки містять її елементи.

Для доступу до елементів матриці використовувалась арифметика покажчиків через розіменування покажчиків, що відповідає вимогам лабораторної роботи.

Програма виконує такі дії:

Відкриває файл з вхідними даними.
Зчитує розміри матриці.
Зчитує елементи матриці.
Знаходить максимальний елемент.
Записує результат у файл assets/output.txt.
Вхідні дані
