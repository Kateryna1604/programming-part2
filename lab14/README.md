## Хід роботи

**Під час виконання лабораторної роботи було створено структуру Mail, яка містить інформацію про електронний лист:**

тему повідомлення;
текст повідомлення;
відправника;
отримувача;
кодування;
тип повідомлення;
коефіцієнт стиснення.

Для представлення користувачів було створено допоміжну структуру Person.

Було реалізовано функції для:

зчитування листів із файлу;
запису результатів у файл;
виведення листів;
формування тексту повідомлення;
обчислення розміру повідомлення;
пошуку листів за автором;
пошуку секретних повідомлень;
підрахунку загального розміру повідомлень;
сортування листів за темою.

Для роботи з пам’яттю використовувалися функції malloc(), realloc() та free().

## Результати виконання

**Програма успішно:**

зчитує дані з текстового файлу;
формує масив повідомлень;
виконує сортування повідомлень;
знаходить повідомлення певного користувача;
знаходить секретні повідомлення;
обчислює сумарний розмір усіх повідомлень;
записує результати у вихідний файл.
