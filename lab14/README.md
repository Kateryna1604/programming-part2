# Lab14 - Structured Data (Mail System)

## 📌 Description
This project implements a simple mail processing system using C structures.
It supports reading mail data from file, processing collections, and writing results to output file.

## 📁 Project structure
- src/ — source code
- test/ — unit tests
- assets/ — input file
- dist/ — output file

## ▶️ Run program

```bash
make
./main.bin ./assets/input.txt ./dist/output.txt
